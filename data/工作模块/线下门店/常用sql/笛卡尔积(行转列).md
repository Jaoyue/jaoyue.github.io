### 使用mysql.help_topic工具表做行转列的操作时发现, 当数据的个数大于553时, 多余的数据就转换失败了, 会丢数据, 因为mysql.help_topic的id个数就是553, 所以这里的mysql.help_topic换成任意一个id连续的表都是可以的, 只是mysql.help_topic的id是从0开始的, 普通表的id是从1开始, sql要稍微调整一下
```plsql
SELECT
	g.id,
	g. NAME,
	substring_index(
		substring_index(
			g.user_ids,
			',',
			b.help_topic_id + 1
		),
		',' ,- 1
	) AS user_id
FROM
	sp_train_user_group g
JOIN mysql.help_topic b ON b.help_topic_id < (
	length(g.user_ids) - length(
		REPLACE (g.user_ids, ',', '')
	) + 1
)
where g.delete_status is null


select * from mysql.help_topic
```

```plsql
SELECT
	bu.id,
	bu.NAME,
	bu.user_id 
FROM
	(
SELECT
	g.id,
	g.NAME,
	substring_index( substring_index( g.user_ids, ',', b.id ), ',',- 1 ) AS user_id 
FROM
	sp_train_user_group g
	JOIN sp_store_stock_20200617_bak b ON b.id < ( length( g.user_ids ) - length( REPLACE ( g.user_ids, ',', '' ) ) + 2 ) 
WHERE
	g.id IN ( SELECT group_id FROM sp_train_job_user WHERE delete_flag = 0 ) 
	) bu
	JOIN v_system_user v ON bu.user_id = v.user_id 
	AND v.`status` = 'ENABLED' 
```
