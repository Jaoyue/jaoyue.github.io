在 MySQL 中使用 `IN` 查询时，结果集的顺序通常不是按照 `IN` 子句中指定的顺序返回的。要使结果按 `IN` 中的顺序排序，你可以使用 `FIELD()` 函数。`FIELD()` 函数返回字符串在列表中的位置，可以用来在 `ORDER BY` 子句中指定排序顺序。

假设你有一个表 `my_table`，其中有一列 `id`，并且你想按 `IN` 子句中的顺序对查询结果进行排序：

```sql
SELECT *
FROM my_table
WHERE id IN (3, 1, 4, 2)
ORDER BY FIELD(id, 3, 1, 4, 2);
```

在这个查询中，`FIELD(id, 3, 1, 4, 2)` 会根据 `id` 在 `IN` 子句中的位置返回一个整数，然后 `ORDER BY` 子句会根据这些整数对结果进行排序，从而实现按 `IN` 中指定的顺序返回结果。

这种方法适用于较小的列表。如果列表非常大，可能需要考虑其他方法来优化查询性能。
