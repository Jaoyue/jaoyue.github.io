### 通过spring注解<font style="color:#bbb529;background-color:#2b2b2b;">Scheduled实现多线程队列</font>
```java
@Scheduled(cron = "* * * * * ?")
    public void execute0() {
        pnObmMroProcessService.executeTask(5,0);
    }
    @Scheduled(cron = "* * * * * ?")
    public void execute1() {
        pnObmMroProcessService.executeTask(5,1);
    }
    @Scheduled(cron = "* * * * * ?")
    public void execute2() {
        pnObmMroProcessService.executeTask(5,2);
    }
    @Scheduled(cron = "* * * * * ?")
    public void execute3() {
        pnObmMroProcessService.executeTask(5,3);
    }
    @Scheduled(cron = "* * * * * ?")
    public void execute4() {
        pnObmMroProcessService.executeTask(5,4);
    }
```

### 配置类
:::warning
必须加配置类, 否则多个任务共用一个线程

:::

```java
@Configuration
@EnableScheduling
public class SchedulingConfig implements SchedulingConfigurer {
    @Override
    public void configureTasks(ScheduledTaskRegistrar taskRegistrar) {
        taskRegistrar.setScheduler(Executors.newScheduledThreadPool(5)); // 设置5个线程的线程池
    }
}
```
