<font style="color:rgb(51, 51, 51);">在Java中，你可以通过以下方式定义一个抽象类：</font>

1. <font style="color:rgb(51, 51, 51);">使用</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(237, 238, 240);">abstract</font>`<font style="color:rgb(51, 51, 51);">关键字来定义一个抽象类。</font>
2. <font style="color:rgb(51, 51, 51);">在抽象类中，可以定义抽象方法，这些方法没有实现体，以分号结束，并且用</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(237, 238, 240);">abstract</font>`<font style="color:rgb(51, 51, 51);">关键字标记。</font>
3. <font style="color:rgb(51, 51, 51);">也可以定义具体的非抽象方法。</font>
4. <font style="color:rgb(51, 51, 51);">子类继承抽象类时，必须实现抽象类中的所有抽象方法，除非子类也是抽象类。</font>

### 示例:
<font style="color:#2F4BDA;">一父多子, 儿子实现父的抽象方法, 在controller中引入某个子, 用子调用父的方法, 父的方法又调用子的方法, 此时子的方法会自动执行引入的子的方法. (多入口, 一个通道, 多出口)</font>

# 一个接口多个实现:
<font style="color:#2F4BDA;">接口和抽象类不同, 当存在一个接口多个实现时, 使用@Qualifier()注解指定引入的实现类</font>

```java
public interface SpProductService {
}
```

```java
@Service("product1")
public class SpProductServiceImpl implements SpProductService {
}
```

```java
@Controller
@RequestMapping("/product")
public class ProductController {

    private static final Logger logger = Logger.getLogger(ProductController.class);

    @Autowired
    @Qualifier("product1")
    private SpProductService spProductService;
}
```
