## 2. 历史任务_推送甘特按钮接口

### 2.1 接口基本信息

| 项⽬     | 说明                                           |
| -------- | ---------------------------------------------- |
| 接口名称 | 历史任务_推送甘特按钮                          |
| 接口路径 | `/pyne-agent-server/pnAgentLog/pushTeslaGantt` |
| 请求方法 | POST                                           |
| 接口地址 | `http://10.107.5.55:8085`                      |
| 接口用途 | 触发甘特图数据推送至 Tesla 系统                |

### 2.2 请求头参数

与「历史任务_推送甘特下拉框」接口的请求头参数完全一致，详见 1.2 节。

### 2.3 请求体参数

请求体格式为 JSON，参数说明如下：

| 参数名      | 类型   | 是否必填 | 示例值              | 说明                | 是否必填            |
| ----------- | ------ | -------- | ------------------- | ------------------- | ------------------- |
| id          | String | 是       | 2004134232058626049 | 任务 / 数据唯一标识 | 必填                |
| productName | String | 是       | 芙万 2.0            | 产品名称            | 备件BOM 必填        |
| ganttCode   | String | 是       | ASS_P5              | 甘特图配置编码      | 可维修性评估表 必填 |

### 2.4 请求示例

```json
{
    "id":"2004134232058626049",
    "productName":"芙万2.0",
    "ganttCode":"ASS_P5"
}
```

### 2.5 响应说明

#### 响应数据格式

接口响应以 JSON 格式返回，核心响应字段（通用）：

| 字段名 | 类型    | 说明                       |
| ------ | ------- | -------------------------- |
| code   | Integer | 响应状态码（200 表示成功） |
| msg    | String  | 响应信息描述               |
| data   | Object  | 响应数据（成功时可为空）   |

#### 响应示例（成功）

```json
{
    "code":200,
    "msg":"推送成功",
    "data":null
}
```

#### 响应示例（失败）

```json
{
    "code": 500,
    "message": "推送甘特编码为空!"
}
```

### 总结

1. 两个接口均为 POST 请求，且需携带相同的鉴权 Token（authorization 请求头）；
2. 「下拉框接口」根据 agentType 过滤返回甘特图配置的下拉选项，「按钮接口」传入任务 ID、产品名、甘特编码完成数据推送；
3. 核心参数说明：agentType 为智能体类型（如 ASS/BOM），ganttCode 为具体配置编码（如 ASS_P5），需保持参数值与配置数据一致。
