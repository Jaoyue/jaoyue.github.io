### 表 tineco_agent_cs_css_ms_repair_order_di 不标准的时间参数

1.取出维修次数在1到3次之间的订单的维修订单号和维修次数

SELECT repair_order_no, repair_count FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE repair_count BETWEEN 1 AND 3

2.查询问题描述中包含“电池故障”或“电机损坏”的订单的问题类型和描述

SELECT problem_type, problem_desc FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE problem_desc LIKE '%电池故障%' OR problem_desc LIKE '%电机损坏%'

3.统计各区域的维修订单总数

SELECT region, COUNT(*) AS repair_order_total FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di GROUP BY region

4.按维修订单状态分组，计算每个状态的订单数量和平均维修次数

SELECT repair_order_status, COUNT(*) AS order_count, AVG(repair_count) AS avg_repair_count FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE repair_count IS NOT NULL GROUP BY repair_order_status

5.按年月分组（以完成时间为准），统计每月的完成订单数

SELECT DATE_FORMAT(finish_time, '%Y-%m') AS year_month, COUNT(*) AS completed_order_count FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE finish_time IS NOT NULL GROUP BY DATE_FORMAT(finish_time, '%Y-%m') ORDER BY year_month

6.按服务商编码分组，计算每个服务商的订单总数和SAP推送成功数, 表头包含服务商名称

SELECT servicer_code AS 服务商编码, servicer_name AS 服务商名称, COUNT(*) AS 订单总数, SUM(CASE WHEN sap_push_status = 1 THEN 1 ELSE 0 END) AS SAP推送成功数 FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di GROUP BY servicer_code, servicer_name

7.查看创建时间在2025-01-01至2025-12-31之间的订单的创建时间和订单号

SELECT creation_date, repair_order_no FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE creation_date BETWEEN '2025-01-01' AND '2025-12-31'

SELECT creation_date, repair_order_no FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE YEAR(creation_date) = #{year} AND MONTH(creation_date) = #{month}

8.拼接发货省份、城市、区县和详细地址，生成完整发货地址并查询相关订单

SELECT repair_order_no, CONCAT_WS('', send_province_name, send_city_name, send_district_name, send_detail_address) AS full_send_address FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE YEAR(creation_date) = #{year} AND MONTH(creation_date) = #{month}

9.找出维修次数大于该区域平均维修次数的订单的订单号和区域

SELECT repair_order_no, region FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE repair_count > (SELECT AVG(repair_count) FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE region = tineco_agent.tineco_agent_cs_css_ms_repair_order_di.region)

10.用正则匹配查询发货手机号以138开头的订单的发货人姓名和手机号

SELECT send_user_name, send_mobile FROM tineco_agent.tineco_agent_cs_css_ms_repair_order_di WHERE send_mobile REGEXP '^138'

### 表 ecovacs_agent.ecovacs_agent_fin_net_income_paine_df 标准时间参数 

#### 占位符模式 类型选月报, 时间参数 2025年12月

1.查询所有数据

SELECT * FROM ecovacs_agent.ecovacs_agent_fin_net_income_paine_df where year = #{year} and month = #{month}

2.查询每个产品当月的收入合计,从大到小排序

SELECT `prod_line` AS 产品线, `month` AS 月度, SUM(`actual_income`) AS 当月收入合计 FROM ecovacs_agent.ecovacs_agent_fin_net_income_paine_df WHERE year = #{year} AND month = #{month} GROUP BY `prod_line`, `month` ORDER BY 当月收入合计 DESC

3.查询当月每个区域排名收入排名前2的产品和收入

SELECT sale_region, prod_line, actual_income FROM (SELECT sale_region, prod_line, actual_income, ROW_NUMBER() OVER (PARTITION BY sale_region ORDER BY actual_income DESC) AS rn FROM ecovacs_agent.ecovacs_agent_fin_net_income_paine_df WHERE year = #{year} and month = #{month}) t WHERE rn <= 2

1.查询所有的产品系列和项目编号,去重,产品系列不能为空,中文表头

SELECT DISTINCT `prod_series` AS '产品系列', `project_code` AS '项目编号' FROM ecovacs_agent.ecovacs_agent_prod_main_data_df WHERE `prod_series` IS NOT NULL AND `prod_series` != ''
