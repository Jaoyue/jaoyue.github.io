# SQL 配置相关接口文档

## 文档说明

本文档主要描述了 SQL 配置相关的三个核心接口：查询数据库表列表、生成 SQL、测试 SQL 接口的详细信息，包括接口地址、请求方式、请求参数、请求头、请求示例等内容，旨在为开发人员提供接口调用的规范和参考。

## 基础信息

| 项目          | 内容                                                  |
| ------------- | ----------------------------------------------------- |
| 服务域名 / IP | 10.107.5.55                                           |
| 服务端口      | 8085                                                  |
| 基础路径      | /hinton-server/business-analysis/sql/config           |
| 认证方式      | Bearer Token（请求头中携带 authorization 字段）       |

## 接口详情

### 1. 查询数据库表列表接口

#### 接口描述

根据指定的代理编码（agentCode），查询对应的数据库表列表信息。

#### 请求信息

- **请求方式**：GET
- **接口路径**：/tables/pyne（注：路径中最后的 pyne 为代理编码，可根据实际场景替换）
- **完整请求 URL**：http://10.107.5.55:8085/hinton-server/business-analysis/sql/config/tables/pyne
- **请求头**：

| 字段名        | 类型   | 必填 | 说明                                                         |
| ------------- | ------ | ---- | ------------------------------------------------------------ |
| authorization | string | 是   | Bearer Token，示例：Bearer eyJhbGciOiJIUzI1NiJ9...（完整 Token 见示例） |

- **请求参数**：无（代理编码通过 URL 路径传递）

#### 响应信息

- **响应格式**：JSON（具体响应字段需根据实际业务返回定义，示例中暂为空数组）

- 响应状态码

  ：

  - 200：请求成功，返回表列表数据
  - 401：认证失败，Token 无效或过期
  - 500：服务器内部错误

### 2. 生成 SQL 接口

#### 接口描述

根据指定的表名、代理编码和查询提示，自动生成对应的 SQL 语句。

#### 请求信息

- **请求方式**：POST
- **接口路径**：/generate
- **完整请求 URL**：http://10.107.5.55:8085/hinton-server/business-analysis/sql/config/generate
- **请求头**：

| 字段名        | 类型   | 必填 | 说明                                                         |
| ------------- | ------ | ---- | ------------------------------------------------------------ |
| authorization | string | 是   | Bearer Token，示例：Bearer eyJhbGciOiJIUzI1NiJ9...（完整 Token 见示例） |
| Content-Type  | string | 是   | 固定值：application/json（请求体为 JSON 格式时需指定）       |

- **请求体（JSON 格式）**：

| 字段名    | 类型   | 必填 | 说明                                                         |
| --------- | ------ | ---- | ------------------------------------------------------------ |
| tableName | string | 是   | 数据库表名（含库名），示例：ecovacs_agent.ecovacs_agent_cs_aftersale_total_fee_paine_df |
| agentCode | string | 是   | 代理编码，示例：pyne                                         |
| prompt    | string | 是   | 查询提示语，用于描述生成 SQL 的业务需求，示例：查询 2025 年的数据 |

#### 响应信息

- **响应格式**：JSON（具体响应字段需根据实际业务返回定义，示例中暂为空数组）

- 响应状态码

  ：

  - 200：请求成功，返回生成的 SQL 语句
  - 400：请求参数错误（如表名、代理编码为空）
  - 401：认证失败
  - 500：服务器内部错误

## 异常处理说明

1. **认证相关异常**：当请求头中未携带 authorization、Token 格式错误或 Token 过期时，接口返回 401 状态码，需重新获取有效的 Token。
2. **参数相关异常**：请求参数缺失、格式错误或不符合业务规则时，接口返回 400 状态码，需根据返回的错误提示调整参数。
3. **服务器内部异常**：接口返回 500 状态码时，需联系服务端开发人员排查服务端问题。

## 补充说明

1. 示例中的 Token 为临时测试 Token，实际使用时需替换为有效的 Token。
2. 接口的响应数据结构需根据业务实际返回结果进行补充和完善。
3. 代理编码（agentCode）为业务标识，需根据实际业务场景传入正确的值。
