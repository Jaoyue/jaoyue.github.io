# 系统问题与故障上报 · 简易搜索分页接口

## 1. 接口信息

| 项 | 内容 |
|---|---|
| 接口名 | 简易搜索分页查询（活动保障复盘专用） |
| 请求方式 | POST |
| Content-Type | application/json |
| 路径 | `/hinton-agent-mario-server/api/systemFaultSubmission/searchPageList`（`context-path` 见 `application.yml`，类上 `@RequestMapping("/api/systemFaultSubmission")`） |
| 返回结构 | `Result<IPage<OpsSystemFaultSubmissionVo>>`，与 `/api/systemFaultSubmission/pageList` 完全一致 |
| 排序 | `create_time DESC` |
| 软删过滤 | 只查 `is_deleted = 0` |

## 2. 请求参数（`OpsSystemFaultSubmissionSearchQuery`）

继承 `PageRequest` 的分页字段。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `departments` | `List<String>` | 否 | 部门，**多选**，命中条件为 `department IN (...)`；为空/不传表示不限部门。部门值必须与库里 `department` 字段完全一致（精确匹配） |
| `occurrencTime` | `List<String>` | 否 | 发生时间范围，格式 `["开始日期", "结束日期"]`，如 `["2026-08-01", "2026-08-31"]`。只传 1 个元素时仅生效下界；按 `DATE_FORMAT(occurrenc_time,'%Y-%m-%d')` 比较 |
| `searchKey` | `String` | 否 | 搜索关键字，**故障编号（`question_no`）或问题描述（`problem_description`）模糊匹配**（`LIKE %key%`），两者 OR 关系 |
| `pageNo` | `Integer` | 否 | 页码，默认 1（`PageRequest` 分页字段） |
| `pageSize` | `Integer` | 否 | 每页条数（`PageRequest` 分页字段） |

### 请求示例

```json
{
  "departments": ["信息技术部", "供应链IT"],
  "occurrencTime": ["2026-08-01", "2026-08-31"],
  "searchKey": "订单",
  "pageNo": 1,
  "pageSize": 10
}
```

## 3. 响应结构

统一响应体 `Result<T>`（`gauss.boot.common.dto.response.Result`）：`code`（0 为成功）、`msg`、`data`。

`data` 为 MyBatis-Plus `IPage`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `records` | `OpsSystemFaultSubmissionVo[]` | 当前页数据 |
| `total` | `long` | 总条数 |
| `size` | `long` | 每页条数 |
| `current` | `long` | 当前页 |
| `pages` | `long` | 总页数 |

## 4. 筛选逻辑说明

1. 三个条件全部可选，未传即不过滤；条件之间是 **AND** 关系。
2. 部门为精确 `IN` 匹配，不是模糊查询，前端下拉项的值需与库内 `department` 保持一致。
3. `searchKey` 只匹配 `question_no` 与 `problem_description` 两列，不参与其他字段。
4. 结果按 `create_time DESC` 排序。
5. 该接口是 `/pageList` 的轻量版：只支持部门、发生时间、关键字三项条件；如需按故障等级、处理状态、恢复时间、复盘时间等更多条件筛选，请走 `/pageList`。
