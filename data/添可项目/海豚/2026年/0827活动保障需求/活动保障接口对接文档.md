### 分页查询活动保障列表

|   |   |
|---|---|
|项目|内容|
|接口地址|/api/activityAssurance/pageList|
|请求方式|POST|
|Content-Type|application/json|

**入参说明：**

|   |   |   |   |
|---|---|---|---|
|字段|类型|必填|说明|
|pageNum|Integer|是|页码，从1开始|
|pageSize|Integer|是|每页条数|
|activityName|String|否|活动名称（模糊查询）|
|activityStatus|String|否|活动状态（PENDING/PROCESSING/COMPLETED/REVIEWED）|
|assuranceLeader|String|否|保障负责人（模糊查询）|
|assuranceDept|String|否|保障部门|
|createTime|List<String>|否|创建时间范围，如 ["2026-08-01 00:00:00","2026-08-31 23:59:59"]|

**入参示例：**

{

"pageNum": 1,

"pageSize": 10,

"activityName": "双11",

"activityStatus": "PENDING"

}

**返回字段说明：**

**外层响应：**

|字段|类型|说明|
|---|---|---|
|code|Integer|状态码，200表示成功|
|msg|String|提示信息|
|message|String|提示信息（兼容字段，同 msg）|
|data|Object|分页数据|

**data 分页对象：**

|字段|类型|说明|
|---|---|---|
|records|Array|活动列表（OpsActivityAssuranceVo 数组）|
|total|Long|总记录数|
|current|Long|当前页码|
|size|Long|每页条数|
|pages|Long|总页数|

**records 列表元素（OpsActivityAssuranceVo）：**

|字段|类型|说明|
|---|---|---|
|id|Long|主键ID|
|activityNo|String|活动编号（如 ATHB2606010001）|

|assuranceLeader|String|保障负责人姓名|
|assuranceLeaderId|String|保障负责人域账号|
|assuranceLeaderAi|String|AI 推荐的保障负责人姓名|
|assuranceLeaderIdAi|String|AI 推荐的保障负责人域账号|
|activityStatus|String|活动状态（PENDING 待保障 / PROCESSING 保障中 / COMPLETED 已完成 / REVIEWED 已复盘）|
|submitterName|String|提报人姓名|
|submitterAccount|String|提报人域账号|
|submitterSupervisorAdCode|String|提报人直属上级域账号|
|startTime|String|活动开始时间（格式：yyyy-MM-dd HH:mm:ss）|
|endTime|String|活动结束时间（格式：yyyy-MM-dd HH:mm:ss）|
|reviewTime|String|复盘时间（格式：yyyy-MM-dd HH:mm:ss）|
|reviewStatus|String|复盘状态（DRAFT 草稿 / REVIEWING 复盘中 / SUBMITTED 已提交）|
|reviewGuardFlag|String|复盘守门标识（NOT_GUARDED 未守门 / GUARDED 已守门）|
|reviewGuardType|String|复盘守门类型（SILICON_GUARDED 硅基守门 / CARBON_GUARDED 碳基守门）|

|aiActionStatus|String|AI 行动计划状态（如 REGENERATED 已重新生成）|
|taskPlatformTaskId|String|任务中心守门任务ID|
|timelines|Array|时间轴列表（OpsActivityTimelineVo）|
|actionPlans|Array|行动计划列表（OpsActivityActionPlanVo，列表接口返回）|
|attachments|Array|活动附件列表（AttachmentDto）|

**timelines 元素（OpsActivityTimelineVo）：**

|字段|类型|说明|

### 查询活动详情

|   |   |
|---|---|
|项目|内容|
|接口地址|/api/activityAssurance/getDetail/{id}|
|请求方式|GET|
|Content-Type|application/json|

**路径参数：**

|字段|类型|必填|说明|
|---|---|---|---|
|id|Long|是|活动保障主键ID（如 14）|

**返回字段说明：**

外层响应同「分页查询活动保障列表」（code / msg / message / data）。其中 **data 为 OpsActivityAssuranceVo 对象**，字段与分页列表的 `records` 元素完全一致并额外包含以下子对象：

**data.actionPlans 元素（OpsActivityActionPlanVo）：**

|字段|类型|说明|
|---|---|---|
|id|Long|行动计划主键ID|
|activityId|Long|关联活动主表ID|
|title|String|行动计划标题|
|category|String|计划分类（如 应急恢复 / 原因排查 / 根本解决）|
|objective|String|目标|
|measure|String|措施（多行文本）|
|responsiblePerson|String|责任人姓名|
|responsiblePersonId|String|责任人ID（域账号）|
|department|String|责任部门|
|expectedCompletionTime|String|预计完成时间（yyyy-MM-dd HH:mm:ss）|
|guardStatus|String|守门状态（NOT_GUARDED 未守门 / GUARDED 已守门）|
|guardType|String|守门类型（SILICON_GUARDED 硅基 / CARBON_GUARDED 碳基，为空时可能不返回）|
|isEdited|Integer|是否经过人工编辑（0否 1是）|
|isPushed|Integer|是否已推送任务中心（0否 1是）|
|isAnnotated|Integer|是否已批注（0否 1是）|
|taskStatus|String|任务中心状态（NOT_STARTED 未开始 / IN_PROGRESS 进行中 / DONE 已完成，为空时可能不返回）|
|taskPlatformTaskId|String|任务中心任务ID（未推送时为空）|
|annotation|String|批注内容（未批注时为空）|
|createBy|String|创建人域账号|
|createTime|String|创建时间（yyyy-MM-dd HH:mm:ss）|
|updateBy|String|修改人域账号|
|updateTime|String|修改时间（yyyy-MM-dd HH:mm:ss）|
|isDeleted|Boolean|是否删除|
|version|Integer|版本号|
|operationLogs|Array|操作日志列表（OpsActivityActionPlanLogVo）|

**data.actionPlans[].operationLogs 元素（OpsActivityActionPlanLogVo）：**

|字段|类型|说明|
|---|---|---|
|id|Long|主键ID|
|actionPlanId|Long|关联行动计划ID|
|activityId|Long|关联活动ID|
|operationType|String|操作类型（如 CREATE 新增 / EDIT 编辑 / ANNOTATE 批注）|
|operationDesc|String|操作描述|
|afterValue|String|变更后内容（JSON 字符串）|
|operatorAccount|String|操作人域账号|
|operatorName|String|操作人姓名|
|createBy|String|创建人域账号|
|createTime|String|创建时间（yyyy-MM-dd HH:mm:ss）|

**data.attachments 元素（AttachmentDto）：**

|字段|类型|说明|
|---|---|---|
|name|String|附件名称|
|type|String|附件类型（如 xlsx / pdf / docx）|
|url|String|附件下载地址|

### 创建活动

|   |   |
|---|---|
|项目|内容|
|接口地址|/api/activityAssurance/create|
|请求方式|POST|
|Content-Type|application/json|

AI 相关字段（aiActivityLevel、assuranceLeader、assuranceLeaderId、assuranceDeptAi、assuranceLeaderAi 等）由系统调用 AI 自动生成并回填，**无需在入参中传入**。

**入参说明（OpsActivityAssuranceDto）：**

| 字段           | 类型     | 必填  | 说明                              |
| ------------ | ------ | --- | ------------------------------- |
| id           | Long   | 否   | 主键ID，编辑已有活动时传入（新增不传）            |
| activityNo   | String | 否   | 活动编号（新增时由系统生成，一般无需传）            |
| activityName | String | 是   | 活动名称                            |
| activityDesc | String | 是   | 活动描述                            |
| startTime    | String | 是   | 活动开始时间（yyyy-MM-dd HH:mm:ss）     |
| endTime      | String | 是   | 活动结束时间（yyyy-MM-dd HH:mm:ss）     |
|              |        |     |                                 |
| timelines    | Array  | 否   | 活动时间轴列表（OpsActivityTimelineDto） |
| attachments  | Array  | 否   | 活动附件列表（AttachmentDto）           |

**timelines 元素（OpsActivityTimelineDto）：**

|字段|类型|必填|说明|
|---|---|---|---|
|id|Long|否|主键ID|
|activityId|Long|否|关联活动主表ID|
|startTime|String|是|开始时间（yyyy-MM-dd HH:mm:ss）|
|endTime|String|是|结束时间（yyyy-MM-dd HH:mm:ss）|
|coreTaskDesc|String|是|核心任务说明|

### 保存活动

|              |                                 |
| ------------ | ------------------------------- |
| 项目           | 内容                              |
| 接口地址         | /api/activityAssurance/save     |
| 请求方式         | POST                            |
| Content-Type | application/json                |

> 用于保存用户**手动选择**的保障负责人与保障部门（即对 AI 推荐的 `assuranceDept` / `assuranceLeader` 做人工纠偏）。本接口**只更新保障部门与负责人两个维度**，不涉及活动名称、时间、时间轴、附件等字段，也不触发 AI 方案的重新生成。
>
> 与「创建活动」（`/api/activityAssurance/create`）的区别：create 用于新建/整体编辑活动主信息，save 用于在活动详情中单独保存手选的负责人与部门。

**入参说明（OpsActivityAssuranceDto）：**

|字段|类型|必填|说明|

|id|Long|是|活动保障主键ID（由创建活动接口返回）|

  "code": 200,
  "message": "success"
}

### 复盘报告人工纠偏

|   |   |
|---|---|
|项目|内容|
|接口地址|/api/activityAssurance/review/correct|
|请求方式|POST|
|Content-Type|application/json|

> 基于指定活动，保存一条人工编辑后的复盘报告新版本（source=人工编辑）。与「方案人工纠偏」类似，不修改原版本，新增的复盘版本默认守门（reviewGuardFlag=GUARDED、reviewGuardType=CARBON_GUARDED，即碳基守门）。

**入参说明（依据后端 OpsActivityReviewEditVO）：**

|字段|类型|必填|说明|
|---|---|---|---|
|activityId|Long|是|活动保障ID|
|reviewReport|String|是|人工纠偏后的复盘报告内容（Markdown）|

**入参示例：**

```json
{
  "activityId": "14",
  "reviewReport": "3432432400000000000000000000000000000000000000000000000"
}
```
