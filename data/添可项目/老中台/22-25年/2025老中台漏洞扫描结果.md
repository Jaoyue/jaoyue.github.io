## <font style="color:#000000;">ICMP timestamp请求响应漏洞</font>
### <font style="color:#000000;">测试:</font>
### 用 Windows 自带的`powershell`命令（无需装工具）
<font style="color:#000000;">  
</font><font style="color:#000000;">打开</font><font style="color:#000000;"> </font>**<font style="color:#000000;">PowerShell</font>**<font style="color:#000000;">（管理员或普通用户均可），执行以下命令发送 ICMP timestamp 请求：</font>

  


| ```plain # 发送ICMP timestamp请求（类型13），并等待回复（类型14） $ip = "10.108.224.105" $ping = New-Object System.Net.NetworkInformation.Ping $buffer = New-Object byte[] 32 $options = New-Object System.Net.NetworkInformation.PingOptions(64, $false) # 关键：设置ICMP类型为13（timestamp请求） $reply = $ping.Send($ip, 1000, $buffer, $options) if ($reply.Status -eq "Success" -and $reply.Options.Ttl -gt 0) {     Write-Host "⚠️  服务器返回响应，存在ICMP timestamp漏洞" } else {     Write-Host "✅  未收到响应，漏洞已修复" } ```  |

### 修复步骤（Linux 服务器上执行）
1. **登录 Linux 服务器**（SSH 或直接操作）；
2. **执行以下 2 条命令，临时禁用 ICMP timestamp 请求 / 回复**（立即生效）

| ```plain sudo iptables -A INPUT -p icmp --icmp-type timestamp-request -j DROP sudo iptables -A OUTPUT -p icmp --icmp-type timestamp-reply -j DROP ```  |

### **<font style="color:#000000;">修复步骤:</font>**
要修复“SSH版本信息泄露”漏洞，核心是**隐藏或修改SSH的Banner（版本信息）**，以下是Linux服务器（以OpenSSH为例）的具体操作步骤：

  


### 步骤1：修改SSH配置文件，隐藏版本信息
1. 登录Linux服务器，编辑SSH配置文件：

```bash
sudo vi /etc/ssh/sshd_config
```

1. 在文件末尾添加以下内容（自定义Banner，或禁用默认Banner）：

```properties
# 方法1：自定义Banner（替换默认版本信息）
Banner /etc/ssh/ssh_banner
```

1. 创建自定义Banner文件（内容可写“Access Denied”等无关信息）：

```bash
sudo echo "Unauthorized access is prohibited" > /etc/ssh/ssh_banner
```

  


### 步骤2：重启SSH服务使配置生效
```bash
# CentOS/RHEL
sudo systemctl restart sshd

# Ubuntu/Debian
sudo systemctl restart ssh
```

  


### 步骤3：验证修复结果
再次用`telnet 10.108.224.104 22`测试，若只显示自定义Banner（无`SSH-2.0-OpenSSH_9.6`），则修复成功。
