# 门店商品名称配置查询接口 - 开发设计文档

## 1. 需求概述

在 `SieApiController` 中新增一个查询门店商品名称配置数据的 API 接口，支持根据 `modifyTime`（修改时间）时间范围查询最新数据，供 SIE 系统调用同步门店商品名称配置信息。

## 3. API 设计

### 3.1 接口地址

```
POST /api/api-store/getProductTerminalInfoList
```

### 3.2 请求参数（JSON Body）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `startTimeStr` | String | 是 | 修改时间起始范围，格式 `yyyy-MM-dd HH:mm:ss` |
| `endTimeStr` | String | 是 | 修改时间截止范围，格式 `yyyy-MM-dd HH:mm:ss` |
| `pageIndex` | Integer | 否 | 页码，从 1 开始，默认 1 |

## 4. 代码改动方案

### 4.1 新建查询条件类

新建 `ProductTerminalInfoSyncConditions.java`，继承 `EcovacsPage` 自带分页参数：

```java
@Data
public class ProductTerminalInfoSyncConditions extends EcovacsPage {
    /** 修改时间起始范围（格式：yyyy-MM-dd HH:mm:ss） */
    private String startTimeStr;
    /** 修改时间截止范围（格式：yyyy-MM-dd HH:mm:ss） */
    private String endTimeStr;
}
```

### 4.2 DAO 层

无需新增方法。直接复用 `GenericRepository` 的 `findByPage` 方法，在 Service 层拼装 `Restrictions` 查询条件。

---

### 4.3 Service 层新增方法

**接口：** `ProductTerminalInfoService.java`

```java
/**
 * 根据 modifyTime 时间范围分页查询门店商品名称配置
 * @param conditions 查询条件（含 startModifyTime/endModifyTime 及分页参数）
 * @return Result 包装的分页结果
 */
Result findListByModifyTimeRange(ProductTerminalInfoSyncConditions conditions);
```

**实现：** `ProductTerminalInfoServiceImpl.java`

```java
@Override
public Result findListByModifyTimeRange(ProductTerminalInfoSyncConditions conditions) {
    SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
    List<SimpleExpression> expressions = new ArrayList<>();
    try {
        expressions.add(Restrictions.ge("modifyTime", sdf.parse(conditions.getStartTimeStr()).getTime(), false));
        expressions.add(Restrictions.le("modifyTime", sdf.parse(conditions.getEndTimeStr()).getTime(), false));
    } catch (Exception e) {
        return Result.error("时间格式错误，请使用 yyyy-MM-dd HH:mm:ss 格式");
    }
    Page<SpProductTerminalInfo> pageList = productTerminalInfoDao.findByPage(
            expressions, "order by modifyTime desc", conditions.getPageRequest());
    return Result.success(pageList);
}
```

---

### 4.4 Controller 层新增接口

**文件：** `SieApiController.java`

```java
/**
 * 查询门店商品名称配置列表（根据 modifyTime 时间范围）
 * 供 SIE 系统同步配置数据使用
 *
 * @param conditions 查询条件（含 startModifyTime/endModifyTime 及分页参数）
 * @return Result 包装的分页数据
 */
@RequestMapping(value = "getProductTerminalInfoList", method = RequestMethod.POST)
public Result getProductTerminalInfoList(@RequestBody ProductTerminalInfoSyncConditions conditions) {
    try {
        return productTerminalInfoService.findListByModifyTimeRange(conditions);
    } catch (Exception e) {
        log.error(e.getMessage(), e);
        return Result.error(e.getMessage());
    }
}
```

> 注意：需要在 `SieApiController` 中注入 `ProductTerminalInfoService`：
> ```java
> @Autowired
> private ProductTerminalInfoService productTerminalInfoService;
> ```

## 5. 依赖注入说明

`SieApiController` 位于 `store-mgr` 模块，`ProductTerminalInfoService` 位于 `store-base` 模块。需确认：

1. `store-mgr` 的 `pom.xml` 是否已依赖 `store-base`（一般已依赖）
2. `ProductTerminalInfoService` 是否已注册为 Spring Bean（`@Service` 已标注，确认无误）
3. 在 `SieApiController` 中新增：`@Autowired private ProductTerminalInfoService productTerminalInfoService;`

---

## 6. 分页说明

- 前端/调用方传入 `pageIndex`（从1开始）和 `pageSize`
- 后端使用 Spring Data 的 `PageRequest.of(pageIndex - 1, pageSize)` 转换（Spring Data 页码从0开始）
- 返回 `Page` 对象，包含 `content`（数据列表）、`totalElements`（总条数）、`totalPages`（总页数）

## 8. 风险点与注意事项

| 风险点 | 说明 | 应对措施 |
|--------|------|----------|
| `modifyTime` 精度为毫秒 | DB 存毫秒时间戳，入参是日期字符串 | Service 层用 `SimpleDateFormat.parse().getTime()` 转换 |
| 时间格式错误 | 调用方可能传入非法格式 | Service 层捕获 `ParseException`，返回明确错误提示 |
| 大数据量查询 | 时间范围过大可能返回大量数据 | 限制 `pageSize` 最大值（建议2000），强制分页 |
| `store-mgr` 对 `store-base` 的依赖 | 需确认模块依赖关系 | 检查 `pom.xml`，若未依赖需新增 |
| 时区问题 | 时间戳与时区无关，但调用方可能传错 | 接口文档中示例说明时间戳获取方式 |
| `Restrictions` 空值处理 | `ignoreNull=true` 时空值条件自动忽略 | 确认 `Restrictions.eq(..., true)` 的行为符合预期 |

## 10. 附录：Restrictions 工具类说明

项目中使用的 `Restrictions` 类封装了查询条件，关键方法：

- `Restrictions.eq(field, value, ignoreNull)` — 等于条件，`ignoreNull=true` 时 value 为空则忽略该条件
- `Restrictions.ge(field, value, ignoreNull)` — 大于等于
- `Restrictions.le(field, value, ignoreNull)` — 小于等于
- `Restrictions.like(field, value, ignoreNull)` — 模糊查询

在 `ProductTerminalInfoServiceImpl.findPageList` 中有完整的使用示例可供参考。
