# 星厨订单开发

## 大货赠品关系管理

### 建表
```sql
-- Vx.y__IMS_PRODUCT_GIFT_RELATION_ADD.sql
CREATE TABLE IF NOT EXISTS `ims_product_gift_relation` (  
  `relation_id`       bigint(20)   NOT NULL COMMENT '主键ID',  
  `goods_sap_id`      varchar(64)  DEFAULT '' COMMENT '大货SAP ID',  
  `goods_name`        varchar(255) DEFAULT '' COMMENT '大货名称',  
  `gift_sap_id`       varchar(64)  DEFAULT '' COMMENT '赠品SAP ID',  
  `gift_name`         varchar(255) DEFAULT '' COMMENT '赠品名称',  
  `delete_flag`       int(11)      NOT NULL DEFAULT '0' COMMENT '删除标识 1-删除 0-未删除',  
  `version_num`       int(11)      NOT NULL DEFAULT '0' COMMENT '版本号',  
  `created_by`        int(11)      NOT NULL DEFAULT '-1' COMMENT '创建人',  
  `creation_date`     datetime     DEFAULT NULL COMMENT '创建时间',  
  `last_updated_by`   int(11)      NOT NULL DEFAULT '-1' COMMENT '更新人',  
  `last_update_date`  datetime     DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',  
  `last_update_login` int(11)      NOT NULL DEFAULT '-1' COMMENT '最后登录人',  
  PRIMARY KEY (`relation_id`),  
  KEY `idx_goods_sap_id` (`goods_sap_id`),  
  KEY `idx_gift_sap_id` (`gift_sap_id`)  
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='大货赠品关系表';
```

## 一件代发(星厨)
> 注：推发货通知单要拆开，大货和赠品分开推发货通知单


### 审批流
StarChefConsignmentOrder 星厨一件代发 
表单地址：/ImsStarChefConsignmentOrderDetails 
回调地址：http://saaf-salesorder-server/salesOrderServer/imsStarChefDropshippingOrder/updateStatus

### 自动生成编码配置
STAR_CHEF_DROPSHIPPING     FXS
![[Pasted image 20260810153433.png]]
### 快码
**STAR_CHEF_DELIVERY_TYPE 星厨发货方式**
KUAIDI 快递 GANXIAN 干线 ZITI 自提
**STAR_CHEF_PARTNER_LEVEL 星厨合伙人等级**
LEVEL_1 一级，LEVEL_2 二级，LEVEL_3 三级
