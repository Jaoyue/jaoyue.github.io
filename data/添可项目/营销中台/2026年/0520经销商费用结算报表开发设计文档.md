# 经销商费用结算报表开发设计文档

**日期：** 2026-05-19

## 一、项目概述

### 1.1 背景与目标

为实现经销商费用结算的自动化与透明化，开发三个核心报表模块，涵盖已提未销费用、当月提货补差、历史库存补差的计算与展示。

### 1.2 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        源数据层                                  │
│  促销Tob价格 | 年度价目表Tob | 门店促销政策 | 门店促销价目表       │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼ 每日同步
┌─────────────────────────────────────────────────────────────────┐
│                      中间表层                                    │
│  dim_promo_tob_price | dim_yearly_price_list |                  │
│  dim_store_promo_policy | dim_store_price_list                  │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼ 数据泵写入
┌─────────────────────────────────────────────────────────────────┐
│                      统计表层                                    │
│  fact_monthly_delivery_comp | fact_historical_inventory_comp    │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼ 自定义报表查询
┌─────────────────────────────────────────────────────────────────┐
│                      自定义报表                                   │
│     报表1:已提未销费用 | 报表2:当月提货补差 | 报表3:历史库存补差         │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼ 报表输出
                           导出Excel
```

## 三、业务逻辑

### 3.1 已提未销费用

| 字段 | 来源 | 计算方式 |
|------|------|----------|
| 数量 | 库存表 | 库存数量 + 进货在途 - 退货在途 |
| 单台价格 | 促销价/年度价 | 客户编码+物料号查促销价，查不到取年度价 |
| 费率 | 业务输入 | 1.13 |
| 费用 | 计算 | 数量 × 单台价格 × 费率 / 1.13 |

**价格获取优先级：**
1. dim_promo_tob_price（客户编码+物料号，优先有效期内，否则取失效期内最新）
2. dim_yearly_price_list（查不到促销价时使用）

---

### 3.2 当月提货补差

| 字段 | 来源 | 计算方式 |
|------|------|----------|
| 提货数量 | 分销订单 | 分销订单发货数量 |
| 补差政策 | 统计表 | 总部政策 + 分部促销政策（T-1有效） |
| 当月补差费用 | 计算 | 提货数量 × 单台补差 / 1.13 |

**过滤条件：** 补差政策为0的不显示

---

### 3.3 历史库存补差

| 字段 | 来源 | 计算方式 |
|------|------|----------|
| 当天库存 | 库存表 | 库存数量 + 进货在途 - 退货在途 |
| 当天单台补差 | 总部+分部(T-1) | 随机取总部，取最高分部 |
| 前一天单台补差 | 总部+分部(T-2) | 同上 |
| 历史补差费用 | 计算 | 库存 × (当天 - 前一天) / 1.13 |

**累计展示：** 当月明细保留，历史求和

## 四、数据泵统计数据

### 5.1 当月提货补差数据泵

```sql
SELECT
    -- 统计日期：T-1 日期
    DATE(DATE_SUB(NOW(), INTERVAL 1 DAY)) AS stat_date,
    t.distributor_code AS distributor_code,
    t.distributor_name AS distributor_name,
    t.material_no AS material_no,
    t.product_name AS product_name,
    t.total_count AS delivery_qty,
    -- 补贴合计
    ROUND(IFNULL(t.zongbu_amount, 0) + IFNULL(t.fenbu_amount, 0), 4) AS comp_policy,
    -- 补贴费用
    ROUND(t.total_count * (IFNULL(t.zongbu_amount, 0) + IFNULL(t.fenbu_amount, 0)) / 1.13, 4) AS comp_fee
FROM (
    SELECT
        dis.distributor_code,
        dis.distributor_name,
        dis.customer_type,
        so.sale_area_name,
        soi.material_no,
        soi.product_name,
        SUM(soi.total_count) AS total_count,
        -- 总部补贴
        IFNULL(sp.zongbu_amount, 0) AS headquarters_makeup,
        -- 分部补贴
        IFNULL(op.fenbu_amount, 0) AS branch_makeup,
        -- 直接关联后取值
        sp.zongbu_amount,
        op.fenbu_amount
    FROM `platform-dist`.dist_ship_sales_order so
    INNER JOIN `platform-dist`.dist_ship_sales_order_item soi
        ON so.sales_order_no = soi.sales_order_no
    INNER JOIN `platform-dist`.dist_distributor dis
        ON so.distributor_code = dis.distributor_code
    -- 关联总部补贴汇总表
    LEFT JOIN (
        SELECT
            sp.distributor_code,
            sp.product_sap_id,
            MAX(sp.makeup_amount) AS zongbu_amount
        FROM `platform-store-report`.sync_ims_product_price_store_promotion_price sp
        WHERE DATE(DATE_SUB(NOW(), INTERVAL 1 DAY)) BETWEEN DATE(sp.start_date) AND DATE(sp.end_date)
          AND sp.delete_flag = 0
        GROUP BY sp.distributor_code, sp.product_sap_id
    ) sp
        ON dis.distributor_code = sp.distributor_code
        AND soi.material_no = sp.product_sap_id
    -- 关联分部补贴汇总表
    LEFT JOIN (
        SELECT
            op.distributor_code,
            op.product_sap_id,
            MAX(op.total_subsidy_amount) AS fenbu_amount
        FROM `platform-store-report`.sync_ims_offline_promotion_policy op
        WHERE DATE(DATE_SUB(NOW(), INTERVAL 1 DAY)) BETWEEN op.start_date AND op.end_date
          AND op.delete_flag = 0
        GROUP BY op.distributor_code, op.product_sap_id
    ) op
        ON dis.distributor_code = op.distributor_code
        AND soi.material_no = op.product_sap_id
    WHERE
        so.order_time >= UNIX_TIMESTAMP(DATE_SUB(CURDATE(), INTERVAL 1 DAY)) * 1000
        AND so.order_time < UNIX_TIMESTAMP(CURDATE()) * 1000
        AND soi.total_count > 0
    GROUP BY
        dis.distributor_code, dis.distributor_name, dis.customer_type,
        so.sale_area_name, soi.material_no, soi.product_name,
        sp.zongbu_amount, op.fenbu_amount
) t
-- 只保留有补贴的数据
WHERE (IFNULL(t.zongbu_amount, 0) + IFNULL(t.fenbu_amount, 0)) > 0
ORDER BY t.distributor_code, t.material_no
```

### 5.2 历史库存补差数据泵

```sql
SELECT
  -- 统计日期（T-1）
  DATE_SUB(CURDATE(), INTERVAL 1 DAY) AS stat_date,
  -- 分销商信息
  d.distributor_code,
  d.distributor_name,
  -- 商品信息
  i.material_no,
  i.product_name,
  -- 当天库存数量（库存基数）
  ROUND(i.inventory_quantity + i.received_way_quantity - i.returned_way_quantity, 4) AS inventory_qty,
  -- 昨天单台补差政策（T-1）= 总部 + 分部
  ROUND(IFNULL(zongbu.zongbu_amount, 0) + IFNULL(fenbu.fenbu_amount, 0), 4) AS daily_comp_policy,
  -- 前一天单台补差政策（T-2）直接从统计表取
  ROUND(IFNULL(stat.prev_comp_policy, 0), 4) AS prev_comp_policy,
  -- 当天补差费用 = 库存 * (T1 - T2) / 1.13
  ROUND(
    (i.inventory_quantity + i.received_way_quantity - i.returned_way_quantity)
    *
    (IFNULL(zongbu.zongbu_amount, 0) + IFNULL(fenbu.fenbu_amount, 0) - IFNULL(stat.prev_comp_policy, 0))
    / 1.13,
    4
  ) AS daily_comp_fee,
  -- 累计补差费用 = 历史累计 + 当天费用
  ROUND(
    IFNULL(stat.accum_comp_fee, 0) +
    (
      (i.inventory_quantity + i.received_way_quantity - i.returned_way_quantity)
      *
      (IFNULL(zongbu.zongbu_amount, 0) + IFNULL(fenbu.fenbu_amount, 0) - IFNULL(stat.prev_comp_policy, 0))
      / 1.13
    ),
    4
  ) AS accum_comp_fee

FROM `platform-dist`.dist_distributor d
INNER JOIN `platform-dist`.dist_inventory i
  ON d.distributor_code = i.distributor_code

-- ===================== 关键：直接关联你提供的两个补贴SQL =====================
-- 左联 昨天总部补贴
LEFT JOIN (
  SELECT sp.distributor_code, sp.product_sap_id, MAX(sp.makeup_amount) AS zongbu_amount
  FROM `platform-store-report`.sync_ims_product_price_store_promotion_price sp
  WHERE DATE(DATE_SUB(NOW(), INTERVAL 1 DAY)) BETWEEN DATE(sp.start_date) AND DATE(sp.end_date)
    AND sp.delete_flag = 0
  GROUP BY sp.distributor_code, sp.product_sap_id
) zongbu
  ON d.distributor_code = zongbu.distributor_code
  AND i.material_no = zongbu.product_sap_id

-- 左联 昨天分部补贴
LEFT JOIN (
  SELECT op.distributor_code, op.product_sap_id, MAX(op.total_subsidy_amount) AS fenbu_amount
  FROM `platform-store-report`.sync_ims_offline_promotion_policy op
  WHERE DATE(DATE_SUB(NOW(), INTERVAL 1 DAY)) BETWEEN op.start_date AND op.end_date
    AND op.delete_flag = 0
  GROUP BY op.distributor_code, op.product_sap_id
) fenbu
  ON d.distributor_code = fenbu.distributor_code
  AND i.material_no = fenbu.product_sap_id
-- ==========================================================================

-- 左联历史统计表，取 T-2 的政策和累计费用
LEFT JOIN `platform-store-report`.stat_historical_inventory_comp stat
  ON d.distributor_code = stat.distributor_code
  AND i.material_no = stat.material_no
  AND stat.stat_date = DATE_SUB(CURDATE(), INTERVAL 2 DAY) -- T-2 统计数据

-- 只保留昨天有补贴的数据
WHERE
  (IFNULL(zongbu.zongbu_amount, 0) > 0) OR
  (IFNULL(fenbu.fenbu_amount, 0) > 0)

ORDER BY
  d.distributor_code,
  i.material_no
```
