项目 内容
接口地址 /api/activityAssurance/pageList
请求方式 POST
Content-Type application/json

入参说明：
字段 类型 必填 说明
pageNum Integer 是 页码，从1开始
pageSize Integer 是 每页条数
activityName String 否 活动名称（模糊查询）
activityStatus String 否 活动状态（PENDING/PROCESSING/COMPLETED/REVIEWED）
assuranceLeader String 否 保障负责人（模糊查询）
assuranceDept String 否 保障部门
createTime List 否 创建时间范围，如 ["2026-08-01 00:00:00","2026-08-31 23:59:59"]

字段 类型 说明

查询活动详情

接口地址 /api/activityAssurance/getDetail/{id}
请求方式 GET
Content-Type application/json

字段 类型 必填 说明
id Long 是 活动保障主键ID（如 14）

isPushed Integer 是否已推送任务中心（0否 1是）

taskStatus String 任务中心状态（NOT_STARTED 未开始 / IN_PROGRESS 进行中 / DONE 已完成，为空时可能不返回）
taskPlatformTaskId String 任务中心任务ID（未推送时为空）
annotation String 批注内容（未批注时为空）
createBy String 创建人域账号
createTime String 创建时间（yyyy-MM-dd HH:mm:ss）
updateBy String 修改人域账号
updateTime String 修改时间（yyyy-MM-dd HH:mm:ss）

version Integer 版本号
operationLogs Array 操作日志列表（OpsActivityActionPlanLogVo）

字段 类型 说明
id Long 主键ID
actionPlanId Long 关联行动计划ID
activityId Long 关联活动ID
operationType String 操作类型（如 CREATE 新增 / EDIT 编辑 / ANNOTATE 批注）
operationDesc String 操作描述
afterValue String 变更后内容（JSON 字符串）
operatorAccount String 操作人域账号
operatorName String 操作人姓名
createBy String 创建人域账号
createTime String 创建时间（yyyy-MM-dd HH:mm:ss）

data.attachments 元素（AttachmentDto）：

字段 类型 说明
name String 附件名称
type String 附件类型（如 xlsx / pdf / docx）
url String 附件下载地址

创建活动
项目 内容
接口地址 /api/activityAssurance/create
请求方式 POST
Content-Type application/json

AI 相关字段（aiActivityLevel、assuranceLeader、assuranceLeaderId、assuranceDeptAi、assuranceLeaderAi 等）由系统调用 AI 自动生成并回填，无需在入参中传入。

id Long 否 主键ID，编辑已有活动时传入（新增不传）

attachments Array 否 活动附件列表（AttachmentDto）

字段 类型 必填 说明
id Long 否 主键ID

endTime String 是 结束时间（yyyy-MM-dd HH:mm:ss）

url String 是 文件访问地址
type String 是 文件类型（如 xlsx）
extName String 否 文件扩展名
size Long 否 文件大小（字节）
